Proof of Reason

The vault only moves when the agent's stated reason is true on-chain, in mandate, and complete.

Who it is for

For principals who have to answer for an automated allocator: vault curators evidencing reallocations to depositors, insurers pricing an AI-allocated vault, platforms deciding what to list.

The agent pays 0.10 USDC per check over x402. The validator earns the same on PASS, WAIT and FAIL, so it is never paid to say yes.

Doctrine

The LLM reads. The chain testifies. TypeScript decides.

Hold the veto, never the keys.

How it works

  1. The agent states its reason as typed claims.
  2. The validator reads chain state at a pinned block and checks every premise.
  3. A signed verdict, PASS, WAIT or FAIL, is written to an ERC-8004 validation registry.
  4. The gate executes only on PASS, asks the owner on WAIT, and reverts on FAIL.

What it does not do: it does not judge whether a decision is wise, only whether its premises are true and allowed.

What it catches

  • A false premise. Stream Finance, November 2025: a hardcoded $1.00 oracle against a $0.26 market, $285M exposed. The TRUE check reads the price at the block.
  • A disallowed action. Grok/Bankr, May 2026: a prompt-injected permission grant, $174k out. The ALLOWED check holds the mandate.

Most agent gates check permissions. Proof of Reason checks premises.

Why Monad

A verdict is only useful if execution follows before the state it checked moves. The gate accepts a verdict for 60 blocks, about 18 seconds at Monad's 0.30 s block time. The first check to execution took 11 blocks, 3.3 seconds. The same 60-block bound on Ethereum L1 is 12 minutes.

Known limits

  • One validator key today; every verdict is on the registry and re-checkable by anyone, and a second validator is the roadmap.
  • The check judges premises and mandate, not whether the decision is wise.
  • The registry is interim until Monad's canonical ERC-8004 validation registry ships.
